# Сайт «Облачный ревизор»

Статический одностраничник: `index.html`, `styles.css`, `app.js`, картинки в `assets/`. Без сборки, зависимостей и внешних CDN — открывается двойным кликом и работает офлайн.

## Что уже есть

- Первый экран с дашбордом и плавающими карточками экономии и риска.
- Блоки: проблема, решение, демо с тремя вкладками, цифры, аудитории, безопасность, FAQ, форма пилота.
- Адаптивность до 360 px, мобильное меню, клавиатурная навигация по вкладкам.
- SEO-мета, Open Graph, favicon, `prefers-reduced-motion`.
- Форма собирает письмо через `mailto:` — без сервера и без «заявка отправлена», которой нет.

## Что заменить перед публикацией

| Что | Где | На что |

| `og:image` | `index.html` | абсолютный URL после деплоя |
| Реквизиты | футер | ИП, ИНН — по желанию |

## Где размещать (ноябрь 2026)

Лендинг статический — **сервер не нужен**. Нужен хостинг, который отдаёт файлы, и домен.

| Вариант | Плюсы | Минусы | Цена |
|---|---|---|---|
| **Timeweb, виртуальный хостинг** | SSL Let's Encrypt, почта для домена, DNS, бэкапы, поддержка 24/7 | панель с CMS-уклоном, но статике не мешает | от 510 ₽/мес |
| **Reg.ru, хостинг** | привычный регистратор, домен и хостинг в одном месте | цены и состав тарифа проверить на сайте | ~200–400 ₽/мес |
| **Yandex Cloud / VK Cloud / Cloud.ru, Object Storage** | платите за гигабайты и трафик, десятки рублей в месяц | дольше настраивать: bucket, website endpoint, DNS, SSL | копейки |
| **Netlify / Vercel / GitHub Pages** | бесплатно, деплой за минуты | зарубежный хостинг; для 152-ФЗ и российских корпораций лучше локально | 0 ₽ |
| **Beget** | был удобным вариантом | **в ноябре 2026 пережил атаку, идёт восстановление** — сейчас не рассматривать | — |

**Рекомендация:** купить домен и виртуальный хостинг в **Timeweb** (или Reg.ru), положить содержимое `startup/site` в `public_html`, включить бесплатный SSL и завести ящик `hello@домен`. Домен `.ru` — от 200 ₽, продление около 399 ₽/год.

Для демо MVP сервер понадобится позже: VPS 2 vCPU / 4 ГБ — от ~1 900 ₽/мес (Timeweb Cloud, Selectel, Cloud.ru). Пока MVP не собран, покупать его незачем: для SberUnity достаточно видео и скриншотов.

**152-ФЗ:** форма отправляет письмо, базы на сервере нет. Всё равно добавьте политику обработки персональных данных и используйте российскую аналитику (Яндекс Метрика), а не зарубежные счётчики. Если позже появится CRM — хранить лиды в России.

## Как опубликовать

### Вариант 1 — Netlify Drop (5 минут, без CLI)

1. Зайдите на `app.netlify.com/drop`.
2. Перетащите папку `startup/site`.
3. Получите URL вида `https://cloudrevisor.netlify.app`.
4. В настройках добавьте свой домен, если он уже куплен.

### Вариант 2 — Vercel

```bash
cd startup/site
npx vercel
```

Framework preset — `Other`, output directory — `.`.

### Вариант 3 — GitHub Pages

Нужен **публичный** репозиторий (на бесплатном плане Pages не работает для приватных).

1. Создайте публичный репозиторий, например `cloudrevisor-site`.
2. Скопируйте туда содержимое `startup/site`.
3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
4. URL будет `https://<username>.github.io/cloudrevisor-site/`.

Если репозиторий проекта остаётся приватным, этот вариант не подойдёт — берите Netlify или Vercel.

## Домен

1. Купить `cloudrevisor.ru` (reg.ru, timeweb, nic.ru — 200–800 ₽/год).
2. В панели регистратора добавить DNS-записи, которые даст хостинг:
   - A-запись на IP хостинга или CNAME на выданный домен;
   - для Netlify/Vercel — их значения из раздела Domains.
3. Дождаться DNS (от минут до нескольких часов), включить HTTPS.
4. Проверить: `https://cloudrevisor.ru` открывается без `www` и с `www`.

## Локальная проверка

```bash
cd startup/site
python3 -m http.server 8080
```

Открыть `http://localhost:8080`.

Или просто открыть `index.html` в браузере — внешние ресурсы не нужны.
