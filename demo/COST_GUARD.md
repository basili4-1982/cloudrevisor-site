# Контроль стоимости демо

## Сейчас: 0 ₽ за запрос

Публичное демо **не вызывает LLM**. Ответы чата заготовлены, числа считает JavaScript. Запросы к демо не создают счёт в RouterAI или у другого провайдера. Хостинг — GitHub Pages, тоже бесплатный.

Токен-бюджет в интерфейсе — **симуляция** контроля стоимости:
- 5 000 токенов на аккаунт;
- до 600 токенов на ответ;
- остаток хранится в `localStorage` по почте;
- сброс демо не обнуляет бюджет аккаунта.

Это UX-демонстрация. Она **не является защитой от обхода**: пользователь может очистить localStorage, сменить почту или открыть демо в другом браузере. Пока LLM не вызывается, обходить нечего.

## Если подключаем реальную LLM

Тогда бюджет должен считаться **на сервере**, а не в браузере. Минимальный контур:

1. **Только подтверждённые аккаунты.** Анонимный посетитель получает заготовленное демо. Живая модель — после подтверждения почты/компании или вручную.
2. **Ключ API только на сервере.** Браузер не видит ключ и не вызывает провайдера напрямую.
3. **Леджер токенов в БД.** Перед вызовом: проверить остаток; после вызова: записать фактические `usage` и списать. Операция атомарная, иначе параллельные запросы обойдут лимит.
4. **Жёсткие лимиты запроса.** `max_tokens: 600`, входной контекст не больше 4 000 токенов, без истории длиннее 3 реплик.
5. **Rate limit.** Например, 4 запроса в минуту, 30 в час на аккаунт, 100 в день на IP.
6. **Глобальный дневной потолок.** Например, 300 ₽/день. При достижении — LLM отключается, демо переходит на заготовленные ответы.
7. **Kill switch.** Переменная окружения `DEMO_LLM_ENABLED=false` мгновенно отключает модель без деплоя.
8. **Кэш.** Канонические вопросы (`billing-db-02`, `orders-api-04`, «сколько экономии») отвечают из кэша — 0 токенов.
9. **Дешёвая модель.** Для демо — DeepSeek V4 Flash / Qwen3, не премиальная. Для отчётов — детерминированный код, LLM только текст.
10. **Алерты.** Логировать `usage.cost`; предупреждать при 50/80/100% дневного лимита.

## Арифметика

| Сценарий | Токенов | Цена при 0,00012 ₽/токен |
|---|---:|---:|
| Один вопрос демо | ~500 | ~0,06 ₽ |
| Аккаунт | 5 000 | ~0,60 ₽ |
| 100 демо-аккаунтов | 500 000 | ~60 ₽ |
| 1 000 демо-аккаунтов | 5 000 000 | ~600 ₽ |

С дневным потолком 300 ₽ даже при наплыве запросов расход не превысит 300 ₽/день. Демо без LLM стоит 0 ₽.

## Что делать при наплыве

- Сразу выключить `DEMO_LLM_ENABLED` — демо продолжит работать на заготовках.
- Понизить дневной лимит и лимит на аккаунт.
- Включить обязательную почту/компанию и ручное подтверждение.
- Отдельный демо-тариф: 5 000 токенов, без автоматического продления.
