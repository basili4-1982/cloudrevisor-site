# Демо «Облачный ревизор»

Кликабельный стенд на синтетических данных: дашборд → карточка ресурса → what-if → блок риска → чат → PDF. Без бэкенда, LLM и внешних библиотек.

## Запуск

```bash
cd startup/demo
python3 -m http.server 8092
```

Открыть `http://localhost:8092`.

Демо также можно открыть напрямую из `index.html` — все ассеты локальные.

## Что работает

- 8 групп экономии и суммы, сходящиеся с `dataset-blueprint.md`: счёт 1 240 000 ₽, экономия 340 000 ₽.
- Фильтры по типу и поиск по имени/владельцу.
- Клик по группе → фильтр таблицы; клик по ресурсу → карточка.
- `orders-api-04`: 8 vCPU / 32 ГБ → 4 / 24, экономия 16 300 ₽/мес, график, replay.
- `billing-db-02`, `vm-risk-01/02`: риск, «не уменьшать», метрики.
- Ползунок целевого пика 60–80%: экономия и число рисков пересчитываются.
- Чат: 5 заготовленных ответов по данным, с чипами инструментов (`get_resource`, `get_metrics`, `replay`). LLM не вызывается.
- PDF: печатная версия отчёта через `window.print()`.
- «Сценарий» в шапке — тайминг демо на 3 минуты.
- Мобильная вёрстка.

## Сценарий на 3 минуты

| Время | Что нажать | Что сказать |
|---|---|---|
| 0:00–0:15 | Дашборд | «Счёт 1 240 000 ₽, 340 тысяч из них — переплата». |
| 0:15–0:45 | «Завышен размер» → `orders-api-04` | «8 vCPU / 32 ГБ → 4 / 24, экономия 16 300 ₽/мес». |
| 0:45–1:05 | «Прогнать историю» | «0 переполнений, запас 18%». |
| 1:05–1:30 | «Объединение» | «Две ВМ не работают одновременно — один хост обслужит обе». |
| 1:30–1:50 | Блок риска → `billing-db-02` | «IOPS 79% при норме 68%: уменьшать нельзя, нужен диск быстрее». |
| 1:50–2:15 | Ползунок 70 → 80% | «Экономия растёт, но и список риска растёт. Решение за клиентом». |
| 2:15–2:35 | Чат: «Почему billing-db-02 в риске?» | «Ответ по числам, с вызовами инструментов». |
| 2:35–3:00 | «Отчёт PDF» | «Тот же отчёт для руководителя. Дальше — пилот». |

## Аккаунт и стоимость

- При первом входе демо просит рабочую почту (или берёт `?account=email` из ссылки) и привязывает бюджет к аккаунту.
- Остаток хранится в `localStorage` по почте; сброс демо его не обнуляет. «Сменить» — новый аккаунт.
- Демо **не вызывает LLM**: ответы заготовлены, поэтому запросы стоят 0 ₽. Токены — симуляция контроля стоимости.
- Если подключаем реальную модель, бюджет и лимиты должны быть на сервере: `COST_GUARD.md`.

## Токен-бюджет

- На сессию — **5 000 токенов**, на один ответ — до 600.
- Оценка стоимости: 5 000 × 0,00012 ₽ ≈ **0,60 ₽**.
- Когда лимит исчерпан, чат блокируется; «Сбросить демо» обнуляет бюджет.
- Это ограничитель демо, а не реальный вызов LLM: ответы заготовлены.

## Что здесь синтетика

Демо-парк, имена ресурсов, метрики и суммы — синтетические. На стенде это подписано. Чат не вызывает LLM: ответы заготовлены, чтобы демо работало офлайн и повторялось.
